# Бэклог задач — Vertical Slice

Задачи выполняются по порядку. Каждую скармливать Claude Code отдельно (не все сразу), после каждой — проверять результат вручную перед следующей.

## 1. Скелет проекта
**Что сделать:** Vite + Phaser 3 + TypeScript, минимальная сцена с пустым экраном и подписью «Hello Dungeon». Проверить, что деплой на Netlify/Vercel работает автоматически при пуше в GitHub.
**Готово, когда:** страница открывается по ссылке из Netlify/Vercel, показывает Phaser canvas.

## 2. Базовые типы и enum'ы
**Что сделать:** `data/` — enum'ы `DoorState` (Locked/Unstable/Echo), `DoorTrigger` (Lost/Abandoned), типы `Player`, `Enemy`, `Node`.
**Готово, когда:** типы компилируются, покрывают все состояния из scope-документа.

## 3. Генератор уровня (упрощённый)
**Что сделать:** `dungeon/LevelGenerator.ts` — генерирует последовательность из 5 узлов на прогон, у каждого узла 2–4 двери со случайным (но валидным) состоянием.
**Готово, когда:** можно сгенерировать прогон и вывести в консоль структуру узлов/дверей.

## 4. Экран Run + взаимодействие с дверями
**Что сделать:** `scenes/RunScene.ts` — визуализация текущего узла, дверей с их статусами, клик/взаимодействие открывает дверь, применяет триггеры (Lost/Abandoned).
**Готово, когда:** игрок видит двери, может их открывать, видно визуальную разницу между статусами.

## 5. Боевая система (AP-экономика)
**Что сделать:** `combat/formulas.ts` + `combat/AttackSystem.ts` — атака с cooldown, компромисс скорость/точность/крит, энергия только от киллов.
**Готово, когда:** можно провести бой с одним типом врага, механика компромисса ощущается в цифрах (протестировать на паре сценариев).

## 6. Adrenaline-механика
**Что сделать:** `combat/AdrenalineSystem.ts` — таймер 3 сек после получения урона, при выживании +15% к скорости, ускоренное падение HP.
**Готово, когда:** механика включается/выключается корректно, видно в UI (индикатор состояния).

## 7. Прогрессия по уровням + завершение прогона
**Что сделать:** переход между 5 уровнями, награда (золото/предметы — просто числа на этом этапе) после 5-го уровня.
**Готово, когда:** можно пройти все 5 уровней подряд от старта до награды.

## 8. Мини-Хаб
**Что сделать:** `scenes/HubScene.ts` — экран с статистикой сессии (уровней пройдено, золота получено) и кнопкой «Начать новый прогон».
**Готово, когда:** после награды игрок попадает в Хаб, может запустить новый прогон, статистика сбрасывается корректно.

## 9. Подключение ассетов Kenney.nl
**Что сделать:** заменить плейсхолдеры-примитивы на спрайты Kenney (двери, персонаж, враг, фон) — по структуре из `CLAUDE.md`, чтобы замена на кастомный арт была лёгкой.
**Готово, когда:** визуально узнаваемая мини-игра, не заглушки-прямоугольники.

## 10. Полный плейтест-прогон
**Что сделать:** финальная проверка — весь путь от старта до Хаба и обратно без багов, стоп-факторов.
**Готово, когда:** можно дать друзьям ссылку и они пройдут игру без вашей помощи и объяснений.
